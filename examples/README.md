# 标准示例项目

这是一套完整的虚构项目资料，用于学习项目资料库的四种格式和导入导出功能。没有真实账户、服务器或可用密钥，域名使用 `example.com`，IP 使用文档专用地址段。

| 文件 | 展示内容 |
| --- | --- |
| 运行与配置说明.md | Markdown 标题、列表、表格、链接、代码块与操作指南 |
| 账号与服务器.txt | 自由文本、项目负责人、虚构账号、服务器与常用链接 |
| .env.example | 全局配置及 `[app]`、`[database]`、`[redis]`、`[storage]` 分组 |
| 应用配置.json | 对象、数组、布尔值、数字、空值与常见敏感字段 |
| project-vault-example.json | 包含四份原始资料的项目 JSON，可完整重新导入 |

## 在应用中查看

首次使用 1.0.0 或更新版本时自动显示本项目。已有资料时，点击左侧“项目”标题旁的书本图标，可导入一份独立示例项目。内容完整且未修改的示例已存在时，会直接打开它；已修改的同名项目保留，另建带编号的示例。

也可新建空项目，导入 `project-vault-example.json` 并保持“作为项目资料包导入”选中，恢复四份资料。其他文件可分别导入，演示四种原始格式。

ENV 中的方括号分组是本工具支持的显示格式。普通 dotenv 加载器可能不支持分组，请按实际项目要求调整后再使用。所有示例密码和密钥均为明确无效的演示标记。
